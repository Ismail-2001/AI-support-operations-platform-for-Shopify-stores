# Setup wizard screenshots

Drop images in this folder (names must match exactly) and they appear
automatically inside the Setup wizard. Until then, the wizard shows a
labelled placeholder instead.

| File | Where it shows up |
|---|---|
| `step-1-shopify-app.png` | Step 1 (Store) — Shopify admin: Settings → Apps and sales channels → Develop apps |
| `step-2-knowledge-import.png` | Step 2 (Knowledge) — the "Import from Shopify" button and chunk count |

Tips: screenshot at browser width ~1200px, crop out unrelated browser chrome,
and keep each image under ~300 KB (PNG or JPG both fine).
